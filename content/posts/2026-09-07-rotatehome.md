## プロジェクトの目的・概要

画面回転ギミックを備えた Android 携帯ゲーム機「RG Rotate」では、標準の Android ランチャーを使うと、縦長スクロールに最適化されていたりコントローラー操作のフォーカス移動がぎこちなかったりする問題がありました。

そこで、**「縦スクロールを完全に排除し、L1/R1 ボタンや左右スワイプで小気味よくページめくりできるゲーム機専用のホームアプリ」** を目指して開発したのが **`rotatehome`** です。

---

## 主な技術スタックや選定理由

- **言語・フレームワーク: Kotlin / Jetpack Compose**
  - アプリ一覧や設定画面、フォーカスアニメーションを宣言的 UI で統一的に構築。
  - 画面回転（ポートレート／ランドスケープ）イベントに対する高速なレイアウト再計算とステート保持。
- **Android パッケージ管理: PackageManager / LauncherApps**
  - インストール済みアプリ情報のリアルタイム取得と、ゲーム・エミュレータ・メディア等のスマートカテゴリ自動分類。
- **CI/CD: GitHub Actions**
  - タグプッシュによる APK 自動ビルド・リリースページへの自動アップロードパイプラインを構築。

---

## 最近実装した機能・修正・工夫したポイント

1. **縦スクロールを廃止した固定グリッド（5x5 = 25個/ページ）**:
   - 画面外へスクロールさせず、1画面25アイコンごとにページネーション（1/2, 1/3...）を実施。
   - 画面の端で十字キーを押した際も自然に次ページへラップアラウンド。
2. **L1 / R1 ボタンによる瞬時のページ＆カテゴリ切り替え**:
   - タブ操作や画面スワイプに加え、上部バンパーボタン（L1/R1）でゲーム機の感覚のままサクサク切り替え可能。
3. **スマートカテゴリ自動仕分け**:
   - 代表的なエミュレータ（AetherSX2, Dolphin, Citra, DuckStation 等）やレトロゲームアプリを自動判別し、「ゲーム」「メディア」「ツール」などへインテリジェントに集約。
4. **CIビルド自動化の安定化**:
   - Windows/Linux 間で問題になりやすい `gradlew` の CRLF 改行コード問題の修正や、GitHub Actions の release 作成パーミッション設定を完了。
