Obsidianで日常のメモや思考ログ、作業ログをとるとき、「いちいちデイリーノートを開いて、所定の位置までスクロールして、タイムスタンプを打って書き込む」という作業に少し摩擦（フリクション）を感じていました。

## 💡 Mumblerとは？

Mumbler は、Obsidian 内で**一人用Twitter**のような感覚で手軽につぶやき・マイクロメモを投稿できるプラグインです。

入力した内容は、その日のデイリーノート（例: `Daily/2026-09-20.md`）の指定見出し配下へ、**逆時系列（新しい投稿が上）** で自動的に追記されます。

### 主な特徴

- ⚡ **クイック入力モーダル**
  - 左リボンアイコン（吹き出しアイコン）またはコマンドパレット（`Mumbler: つぶやきを投稿`）からワンアクションで起動
  - `Cmd + Enter` / `Ctrl + Enter` で瞬時に送信＆クローズ
- 🔁 **連続投稿モード**
  - `Alt + Enter`（Macは `Option + Enter`）を押すと、**モーダルを閉じずに連続投稿**が可能。連投したい思考ログもストレスなく書き込めます
- 📅 **デイリーノートへの自動整形・追記**
  - 現在時刻（`HH:mm`）を自動付与してリスト形式で追記
  - 複数行のつぶやきも自動でインデントされ、Markdown のリスト構造を崩さず綺麗に整形
  - 見出し（デフォルト: `## つぶやき`）配下の一番上に新しい投稿が入るタイムラインスタイル
  - フォルダや当日のノートが存在しない場合は自動生成
- 📱 **iPad・モバイル環境への徹底した最適化**
  - ソフトウェアキーボード展開時に入力欄が隠れないよう、フォーカス時に滑らかに上部へスライドするアニメーションを実装
  - iPad の横画面（Landscape）でもボタンがキーボードに埋もれないよう、レスポンシブに高さを自動調整
- ⚙️ **柔軟な設定**
  - 標準の「デイリーノート（Daily Notes）」コアプラグイン設定（保存先フォルダ・日付フォーマット）との連動
  - 追記先見出しレベル（`H1` 〜 `H6`）および見出し名（`つぶやき`, `Thoughts`, `Log` など）の自由なカスタマイズ

## 🛠️ こだわりポイント & 実装の工夫

### 1. 「書き込むまでのフリクション」を極限まで減らすUI

PCでもiPadでも、何か思いついた瞬間にすぐキーボードを叩けるよう、モーダルオープン時に自動でテキストエリアへフォーカスが当たるようにしています。

また、単発のメモだけでなく思考が溢れて何件か連続で書きたいときのために、`Alt + Enter` による「連続投稿（keepOpen）」を用意しました。

| ショートカット / 操作 | 動作 |
| :--- | :--- |
| **`Cmd + Enter` / `Ctrl + Enter`**（または投稿ボタン） | つぶやきを保存してモーダルを閉じる |
| **`Alt + Enter` / `Option + Enter`** | つぶやきを保存し、モーダルを開いたまま入力欄をクリア |
| **`Esc`**（またはキャンセルボタン） | 投稿せずモーダルを閉じる |
| **リボンアイコンの右クリック** | Mumblerの設定画面をダイレクトに開く |

### 2. iPad / モバイルでの快適なタイピング体験

タブレットやスマートフォンでObsidianを使っていると、モーダルを開いたときに**ソフトウェアキーボードが表示されて入力欄や投稿ボタンが完全に隠れてしまう**という問題が起きがちです。

Mumbler では CSS トランジション（`transition: transform 0.28s cubic-bezier(0.16, 1, 0.3, 1)`）を組み込み、入力エリアにフォーカスが入った瞬間（`:focus-within`）にモーダル全体がスーッと上方にスライドする仕組みを入れました。

さらに、画面の高さが著しく狭くなる **iPad横画面（Landscape）** でも投稿・キャンセルボタンがキーボードに被らないよう、テキストエリアの高さとマージンを動的に最適化しています。

### 3. Markdown構造を壊さない追記ロジック

複数行のメモを投稿した際、単純にそのまま追記するとMarkdownのリスト構造が途切れてしまいます。Mumbler では2行目以降に自動で半角スペース2つのインデントを付与し、綺麗なネストリストとして保存されます。

追記結果の例：

```markdown
## つぶやき

- **11:20** 今日はObsidianプラグイン「Mumbler」をリリースした！
  ブログ記事も書いて公開しよう。
- **10:05** 朝のコーヒーを淹れた。これからコーディング開始。
- **08:30** 起床。天気が良くて気持ちいい。
```

また、Obsidian API の `app.vault.process()` を採用しているため、競合やファイル破損のリスクを最小限に抑えて安全に追記処理が行われます。

## 📦 インストール方法

### BRAT経由（おすすめ）

コミュニティプラグイン [Obsidian42 - BRAT](https://github.com/TfTHacker/obsidian42-brat) を使うと、GitHubリポジトリから直接ワンクリックで導入・自動アップデートが可能です。

1. Obsidianの設定から **BRAT** プラグインをインストールして有効化
2. コマンドパレットで `BRAT: Add a beta plugin for testing` を実行
3. リポジトリURLに以下を入力：
   ```text
   https://github.com/u1e2k/mumbler
   ```
4. インストール完了後、**設定 > コミュニティプラグイン** で `Mumbler` を有効化する

### 手動インストール

1. [Releases](https://github.com/u1e2k/mumbler/releases) から最新の `main.js`, `manifest.json`, `styles.css` をダウンロード
2. ご自身のVault配下の `.obsidian/plugins/mumbler/` フォルダに配置
3. Obsidian の設定でコミュニティプラグインを再読み込みし、`Mumbler` を有効化

## ⚙️ 設定項目

**設定 > コミュニティプラグイン > Mumbler**（またはリボンアイコンを右クリック）から以下の設定を調整できます：

- **コアプラグインの設定を使用する**: ONにすると、標準の「デイリーノート」プラグインで指定しているフォルダや日付フォーマットを自動的に参照します。
- **フォルダ名 / 日付フォーマット**: コアプラグイン設定を使わない場合に、保存先フォルダ（デフォルト: ルート）や Moment.js 形式の日付書式（デフォルト: `YYYY-MM-DD`）を指定可能。
- **見出しレベル**: `H1`（`#`）から `H6`（`######`）まで選択可能。
- **見出し名**: 追記先見出しの文字列（デフォルト: `つぶやき`）。
- **投稿後にデイリーノートを開く**: 投稿完了時にデイリーノートをアクティブタブで表示するかどうかを切り替え可能。
